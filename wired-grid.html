Wired Grid.

An open source spreadsheet app for macOS, Windows, and Linux. Organize data, build formulas, and create charts in workbooks that can open and save Excel files.

Formulas

Use spreadsheet functions and dynamic arrays, with reference highlighting and function hints.

Workbooks and charts

Open and save XLSX, CSV, and TSV files, and visualize data with charts.
