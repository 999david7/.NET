Ghosty.

A native macOS terminal with a newspaper-style interface. The window heading shows your current folder or the command running in the foreground.

What Ghosty can do

View on GitHub ↗

Terminal support

Run shell tools with ANSI colors, mouse reporting, and scrollback.

Tabs and windows

Keep sessions in separate tabs or windows and browse to a folder from the path bar.

Three editions

Choose Broadsheet, Night Edition, or Wired for the terminal’s typography and colors.
