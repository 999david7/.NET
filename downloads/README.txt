This directory contains the macOS DMGs for Keepy, Cloudy, and Ghosty.
Keepy and Ghosty were built from the local project repositories. Cloudy uses
the existing project DMG. These builds are not notarized by Apple.

Publish these files with the website. The other apps download directly from
their GitHub Releases. Run python3 scripts/update-downloads.py from the
website root to refresh the links and prefer published installers when available.
